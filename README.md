# Monster Manor

A multiplayer first-person Halloween escape game for a team in one room: everyone plays in their own
browser, and a big screen shows the map. Fix the fuse box, open the Count's desk, find three iron keys
and get out before dawn, while a vampire, a stitched-together giant, zombies and ghosts hunt the halls.
At dawn the top scorer harvests one of six hanging pumpkins in the graveyard.

Everything is in [`convent/`](convent/) (the folder keeps the name of the game's first version, *Escape the
Convent*). Start with [`convent/README.md`](convent/README.md).

Built with Node.js, Express, Socket.IO and three.js. Code: MIT ([LICENSE](LICENSE)). Art and sound:
see [`convent/ASSETS.md`](convent/ASSETS.md); some sounds are not included, and the game plays without them.
